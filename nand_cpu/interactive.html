Instruction Set

OpMeaning
NOPdo nothing
LOADI nACC = n (immediate)
LOAD aACC = RAM[a]
STORE aRAM[a] = ACC
ADD aACC = ACC + RAM[a]
SUB aACC = ACC - RAM[a]
JUMP aPC = a
JZ aif ACC == 0: PC = a
JNZ aif ACC != 0: PC = a
HALTstop execution
JLT asigned < (N XOR V); after CMP a: if ACC < RAM[a]: PC = a
JOV aif V (signed overflow): PC = a
CMP aACC - RAM[a], flags only (ACC unchanged)

16-bit instruction: [opcode:4][operand:12]. Accumulator machine — one working register (ACC), everything else lives in RAM. label: lines define jump targets; ; starts a comment. ADD/SUB/CMP set the status flags Z (zero), N (sign bit), V (signed overflow) — all built from NAND-derived gates.
